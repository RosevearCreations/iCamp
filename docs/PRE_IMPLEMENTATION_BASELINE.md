## Why the active numbering was reset
The campground design expanded before product implementation began. Added requirements include:
- rental cottages using the live reservation system;
- local destination/event promotion;
- garbage pickup models and paid garbage stickers/tags;
- key-card/keypad/gate security and audited manual overrides;
- road-vehicle registration and day/week passes;
- up to 10 public images for each campsite/cottage;
- zoom-stable map geometry;
- seasonal winterization and winter-readiness;
- permanent-unit ownership/sale/financing workflows;
- events, visitors, recreational devices and waterfront operations;
- and first-class telephone/IVR/DTMF/SMS access.

The engineering baseline remains valid, but its old Build 001 label was retired so all active Build numbers reflect the complete design.
