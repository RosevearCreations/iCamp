# Build 285 — Site 12 map and service pilot

This candidate introduces a tenant-authorized campsite service list that
combines assistance cases and add-on fulfillment without changing either
workflow, links it from map publication, and adds stay-linked guest shortcuts.
The guest's reservation determines the campsite. Assistance remains tied to its
original accommodation; add-on work uses its reservation's current location.
Staff must review delivery reassignment on a site move before fulfillment.

No actual Camp Rosevear map, account, inventory, payment, or ledger is seeded.
The pure regression is a synthetic test, not an authenticated field rehearsal.
The staff overlay uses only existing same-tenant published geometry and the
accessible list retains unplotted sites. The monitor requests a fresh server
view on reconnection, window focus and every 30 seconds while visible. Actual
map publication, payment-to-delivery and ledger reconciliation,
reconnect timing, original account readiness and authenticated cross-tenant
browser acceptance remain open. No real payments, external providers or
original database migrations are authorized by this candidate.

Use the existing versioned map upload and publication controls with authorized
imagery. For pilot acceptance use a checked-in guest and separately authorized
staff on an isolated test tenant; submit a free repair and one priced
firewood order using test tender only. Refresh the monitor; resolve one
without clearing the other. Verify inventory, folio, ledger and scope denial.
Do not mark the pilot ready until the actual end-to-end evidence is recorded.
