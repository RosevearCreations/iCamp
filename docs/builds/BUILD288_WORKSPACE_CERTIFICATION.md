# Build 288 — Administrator and campground workspace certification

This release adds distinct role-specific entry screens, safe account switching,
retirement of the replaced session, visible account context in platform access,
and the selected campground name and roles in its management workspace.
Incorrect account types cannot replace the current session via a role-specific
login. Staff type alone is never a platform grant or campground assignment.

Public browser checks and pure routing regressions do not establish original
account access. Independent owner binding, original database reconciliation,
CampRosevear activation and assignment, and authenticated three-role journeys
remain HOLD until witnessed. No credentials or privileges are changed by
deploying this release. Test account access only in an approved environment.
